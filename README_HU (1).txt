ÁLLATKÁOSZ – ASSETS/ANIMALS
============================

TARTALOM
- pig, capybara, horse, penguin, raccoon: álló póz SVG + átlátszó PNG
- *_run: négy képkockás, vízszintes futóspritesheet SVG + PNG
- *_jump: ugrópóz SVG + PNG
- *_fall: leeső póz SVG + PNG
- preview.html: böngészőben megnyitható animált előnézet
- manifest.json: géppel olvasható fájllista és képkockaméretek

MÉRETEK
Az SVG karakterek névleges képkockamérete 128×128. A PNG álló/ugrás/leesés képek 256×256 méretűek. A futóspritesheet PNG 1024×256: 4 darab 256×256 képkockát tartalmaz egymás mellett. Az SVG futóspritesheet 512×128: 4 darab 128×128-as képkockát tartalmaz.

ANIMÁCIÓ
A futóspritesheet kockái balról jobbra: 0, 1, 2, 3. Javasolt futásanimáció: 8–12 fps. A karakterek oldalnézeti, jobbra néző platformjáték-sprite-ok.
